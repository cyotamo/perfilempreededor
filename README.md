# Sistema de Perfil Empreendedor

Sistema simples, profissional e estático para avaliar o perfil empreendedor de participantes numa feira de empreendedorismo.

## Instituição

Universidade Rovuma  
Faculdade de Ciências Económicas e Empresariais

## Como funciona

- O participante responde a 10 questões.
- Cada resposta recebe pontuação de 0 a 4.
- O sistema calcula automaticamente a percentagem do perfil empreendedor.
- O resultado é mostrado imediatamente no navegador.
- Nenhum dado é guardado, enviado ou partilhado.

## Ficheiros

- `index.html` — página principal do sistema.
- `style.css` — estilos visuais.
- `script.js` — perguntas, cálculo e apresentação do resultado.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Carregue os ficheiros `index.html`, `style.css` e `script.js`.
3. Aceda a **Settings > Pages**.
4. Em **Branch**, escolha `main` e a pasta `/root`.
5. Grave e aguarde o link público do GitHub Pages.

## Observação

Este sistema não substitui uma avaliação psicológica ou empresarial profunda. Serve como ferramenta de sensibilização, orientação e interacção em contexto de feira de empreendedorismo.
